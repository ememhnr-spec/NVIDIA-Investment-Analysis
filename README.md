# NVIDIA Investment Committee Analysis

## Overview
Independent public-markets investment-analysis work sample built as an editable finance deck and supporting Excel model.

## What the project demonstrates
- Historical financial statement analysis
- Revenue and segment analysis
- Trading comparables
- DCF valuation
- WACC / terminal-growth sensitivity
- Scenario analysis
- Investment-committee style presentation

## Company
NVIDIA Corporation (NASDAQ: NVDA)

## Valuation date
2 October 2026 market close.

## Key outputs
- TTM revenue: $303.0bn
- TTM operating income: $197.6bn
- TTM free cash flow: $127.0bn
- Market price: $233.95/share
- Market capitalization: approximately $5.65tn
- Illustrative DCF value: $300.82/share

## Important methodology note
The historical financials are based on NVIDIA's public filings. Market data is based on public market-data sources available at the valuation date.

The forecast, WACC, terminal growth, tax, D&A, CapEx and working-capital assumptions are **illustrative analyst assumptions created for this portfolio exercise**. They are not NVIDIA guidance and should not be presented as company forecasts.
